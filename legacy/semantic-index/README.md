# `@enterstellar-ai/semantic-index` (deprecated)

> **Renamed:** use [`@enterstellar/semantic-index`](https://www.npmjs.com/package/@enterstellar/semantic-index) instead.

Enterstellar moved its npm scope from `@enterstellar-ai` to `@enterstellar`.
This package is a **compatibility shim** that re-exports `@enterstellar/semantic-index` so existing
installs keep working during the transition.

## Migrate

```bash
npm install @enterstellar/semantic-index
```

```diff
- import { ... } from '@enterstellar-ai/semantic-index';
+ import { ... } from '@enterstellar/semantic-index';
```
