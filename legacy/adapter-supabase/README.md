# `@enterstellar-ai/adapter-supabase` (deprecated)

> **Renamed:** use [`@enterstellar/adapter-supabase`](https://www.npmjs.com/package/@enterstellar/adapter-supabase) instead.

Enterstellar moved its npm scope from `@enterstellar-ai` to `@enterstellar`.
This package is a **compatibility shim** that re-exports `@enterstellar/adapter-supabase` so existing
installs keep working during the transition.

## Migrate

```bash
npm install @enterstellar/adapter-supabase
```

```diff
- import { ... } from '@enterstellar-ai/adapter-supabase';
+ import { ... } from '@enterstellar/adapter-supabase';
```
