# `@enterstellar-ai/adapter-firebase` (deprecated)

> **Renamed:** use [`@enterstellar/adapter-firebase`](https://www.npmjs.com/package/@enterstellar/adapter-firebase) instead.

Enterstellar moved its npm scope from `@enterstellar-ai` to `@enterstellar`.
This package is a **compatibility shim** that re-exports `@enterstellar/adapter-firebase` so existing
installs keep working during the transition.

## Migrate

```bash
npm install @enterstellar/adapter-firebase
```

```diff
- import { ... } from '@enterstellar-ai/adapter-firebase';
+ import { ... } from '@enterstellar/adapter-firebase';
```
